範囲： ルーラー（小節番号の帯）をドラッグして選択
強さ

下地（伴奏）を作る

曲の雰囲気を普段の言葉で書いてください。ループの長さ・長調/短調・BPM・楽器の方向性などを書くと反映されます。AIが「設計図」（構成・コード進行・各パートの役割と奏法）を作り、ソフトがそれを音符にします。メロディ用にパート1・2は空けておきます。

設定

キーはこのブラウザ内（localStorage）にだけ保存され、Anthropic の API へ直接送られます。他の場所には送りません。AI機能の利用料金は API の従量課金です。

WAV書き出し

ゲーム用のループ部分は「2周目」を書き出すので、先頭に前の周の余韻が入っており、そのまま繰り返しても継ぎ目が目立ちません。

操作方法

音符

  • 空いている所をクリック：音符を置く（そのまま右へドラッグで長さを伸ばす）
  • 音符をドラッグ：移動 ／ 音符の右端をドラッグ：長さを変える
  • 右クリック：音符を消す（右ボタンのままなぞると連続で消す）
  • Shift＋ドラッグ（空き場所から）：範囲で選択 ／ Shift＋クリック：選択に追加
  • ↑↓：選択した音を半音ずつ移動（Shift で1オクターブ）／ ←→：グリッド分ずらす
  • Delete：選択した音を消す ／ Ctrl+A：このパートの音を全選択
  • Ctrl+C / Ctrl+X / Ctrl+V：音符のコピー・切り取り・貼り付け（貼り付けはカーソル位置へ）
  • 下の「強さ」の帯をドラッグ：音の強さ（ベロシティ）を変える

パートの決まり

  • パートは8つ。各パートは同時に1音まで（重なった音は自動で切り詰められます）。
  • ドラム音源を選んだパートだけは、同じタイミングに3音まで重ねられます。ドラムのパートは1つまでです。

再生・範囲

  • Space：再生／停止（カーソル位置から）／ Home：先頭へ
  • ルーラー（上の小節番号の帯）をクリック：カーソル移動 ／ ドラッグ：小節範囲を選択
  • ルーラーをダブルクリック：その小節にセクションの目印を追加
  • 「範囲ループ」を入れると選んだ範囲だけ繰り返し再生
  • 「つなぎ目試聴」はループ末尾2小節から再生し、先頭に戻る所を確認できます
  • 1〜8キー：パートを切り替え

画面

  • ホイール：上下スクロール ／ Shift＋ホイール：左右スクロール ／ Ctrl＋ホイール：拡大縮小

保存

  • 編集内容はこのブラウザに自動保存されます。ファイルとして残すには「保存」（.bgm.json）を使ってください。
  • 楽譜ファイルの仕様は docs/FORMAT.md、他のClaudeに渡すときの説明は docs/FOR_CLAUDE.md にあります。
