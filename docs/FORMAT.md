# 楽譜ファイル仕様（CustomBGM 形式 v1）

CustomBGMEditor が保存する楽譜ファイル（拡張子 `.bgm.json`）の仕様です。
中身は UTF-8 の JSON で、人間にも AI にも読み書きできます。
音は `engine/bgm-engine.js` がその場で合成します（録音済みの音源は使いません）。

## 全体像

```json
{
  "format": "CustomBGM",
  "version": 1,
  "title": "ダンジョン",
  "bpm": 128,
  "ppq": 48,
  "beatsPerBar": 4,
  "key": { "tonic": "A", "mode": "minor" },
  "intro": { "enabled": true, "bars": 4 },
  "loopBars": 112,
  "sections": [ { "bar": 0, "name": "イントロ" }, { "bar": 4, "name": "A" } ],
  "master": {
    "volume": 0.8,
    "reverb": { "size": 0.6, "damp": 0.5, "level": 0.35 },
    "delay": { "beats": 0.75, "feedback": 0.35, "level": 0.3 }
  },
  "parts": [
    {
      "name": "ベース",
      "instrument": "triBass",
      "params": {},
      "volume": 0.85, "pan": 0, "reverb": 0.05, "delay": 0,
      "mute": false, "solo": false,
      "notes": [[0, 20, 45, 91], [24, 20, 45, 81]]
    }
  ],
  "meta": { "plan": { } }
}
```

`parts` は必ず8個です（足りない分は既定値で補われます）。

## 時間の単位

| 項目 | 値 |
|---|---|
| 拍子 | 4/4 固定（`beatsPerBar` は将来用。常に 4） |
| tick | 4分音符 = **48 tick**（`ppq`） |
| 1小節 | 192 tick |
| 16分音符 / 32分音符 | 12 / 6 tick |
| 8分3連 / 16分3連 | 16 / 8 tick |
| 1 tick の秒数 | `60 / (bpm × 48)` |

テンポは曲の途中で変わりません。

## 曲の構造（イントロとループ）

```
tick 0                     introTicks                         totalTicks
|------ イントロ（任意）-----|------------ ループ部分 ------------|
                            ↑ ここへ戻って無限に繰り返す         ↑
```

- `intro.enabled` が `true` のとき、先頭の `intro.bars` 小節がイントロです。1回だけ流れます。
- `introTicks = intro.enabled ? intro.bars × 192 : 0`
- ループ部分は `loopBars` 小節で、`[introTicks, introTicks + loopBars × 192)` の範囲です。
- `totalTicks = introTicks + loopBars × 192`
- ループの長さは **3分以上10分未満** を推奨します。エディタはこの範囲外のとき警告を出しますが、ファイルとしては有効です。
- 音符の時刻はすべて **曲の先頭（イントロの先頭）からの絶対 tick** です。
- イントロとループの境目をまたぐ音符、曲の終わりを越える音符は、再生時に境目で切られます。

## sections（目印）

`{ "bar": 小節番号（0始まり、イントロ込み）, "name": "名前" }` の配列です。再生には影響しません。

## parts（パート）

| キー | 型 | 説明 |
|---|---|---|
| `name` | 文字列 | 表示名 |
| `instrument` | 文字列 | 音色プリセットID（下表） |
| `params` | オブジェクト | プリセットの値を上書きするパラメータ（省略可、下記） |
| `volume` | 0〜1.5 | 音量 |
| `pan` | -1〜1 | 定位（-1 = 左、1 = 右） |
| `reverb` | 0〜1 | リバーブへ送る量 |
| `delay` | 0〜1 | ディレイへ送る量 |
| `mute` / `solo` | 真偽 | ミュート / ソロ（ソロが1つでもあれば、ソロのパートだけ鳴る） |
| `notes` | 配列 | 音符 |

### 音符

`[開始tick, 長さtick, 音高, 強さ]`

- 音高: MIDI ノート番号（60 = C4 = 中央のド、69 = A4 = 440Hz）。0〜127。
- 強さ: 1〜127（ベロシティ）。
- 読み込み時は `{ "t", "d", "p", "v" }` や `{ "start", "length", "pitch", "velocity" }` のオブジェクト形式も受け付けますが、保存は配列形式です。

### 同時発音の制約（作り込み過ぎ防止のための仕様）

- **通常のパートは同時に1音まで**。同じパート内で音符の時間が重なってはいけません（和音は複数パートに分けて書きます）。
  再生エンジンは、重なっていても後の音が鳴った時点で前の音を離します。
- **ドラム音源のパートは、同じ開始tickに3音まで**。4音目以降は再生されません。
- **ドラム音源のパートは曲全体で1つまで**。
- `CustomBGM.validateScore(score)` で違反を確認できます。

### ドラムの音高割り当て

ドラム音源のパートでは、音高ごとに鳴る音が決まっています。長さは見た目だけで、音の長さには影響しません。

| 音高 | 音 |
|---|---|
| 36 | キック |
| 37 | リム |
| 38 | スネア |
| 39 | クラップ |
| 42 | クローズドハット（オープンハットを止める） |
| 46 | オープンハット |
| 45 / 47 / 50 | タム（低 / 中 / 高） |
| 49 | クラッシュ |
| 51 | ライド |

## 音色プリセット（instrument）

| ID | 名前 | 向き |
|---|---|---|
| `pulse12` | 矩形波 12.5% | 汎用・メロディ |
| `pulse25` | 矩形波 25% | 汎用・メロディ |
| `pulse50` | 矩形波 50% | 汎用・メロディ |
| `pwmLead` | PWM矩形波 | 汎用・メロディ |
| `softSquare` | ソフト矩形波 | 汎用・メロディ |
| `triangle` | 三角波 | 汎用・メロディ |
| `saw` | ノコギリ波 | 汎用・メロディ |
| `sine` | サイン波 | 汎用・メロディ |
| `brass` | シンセブラス | 汎用・メロディ |
| `fmBell` | FMベル | 汎用・メロディ |
| `fmEPiano` | FMエレピ | 和音 |
| `pluck` | プラック | 和音 |
| `pad` | シンセパッド | 和音 |
| `warmPad` | やわらかパッド | 和音 |
| `triBass` | 三角波ベース | ベース |
| `subBass` | サブベース | ベース |
| `synthBass` | シンセベース | ベース |
| `pulseBass` | 矩形波ベース | ベース |
| `fmBass` | FMベース | ベース |
| `drumChip` | ドラム（チップ） | ドラム |
| `drumElectro` | ドラム（エレクトロ） | ドラム |

各プリセットの具体的な値は `engine/bgm-engine.js` の `PRESETS` にあります。

### params（シンセ音色）

省略したキーはプリセットの値（さらに無ければ下の既定値）になります。

| キー | 既定値 | 意味 |
|---|---|---|
| `osc` | `"pulse"` | 波形: `pulse` / `saw` / `tri` / `sine` / `fm` / `supersaw` / `noise` |
| `duty` | 0.5 | 矩形波のデューティ比（0.05〜0.95） |
| `pwmDepth`, `pwmRate` | 0, 2 | デューティ比の揺れ（深さ、Hz） |
| `unison`, `spread` | 1, 12 | supersaw の重ねる数と広がり（cent） |
| `fmRatio`, `fmIndex` | 2, 2 | FM のモジュレータ周波数比と深さ |
| `fmDecay`, `fmSustain` | 0.5, 0.2 | FM の深さの減衰時間（秒）と残る割合 |
| `attack`, `decay`, `sustain`, `release` | 0.003, 0.2, 0.7, 0.1 | 音量エンベロープ（秒、秒、0〜1、秒） |
| `cutoff`, `resonance` | 20000, 0 | ローパスフィルター（Hz、0〜0.95）。19000 以上はフィルターなし |
| `filterEnv`, `filterDecay` | 0, 0.3 | 発音時にカットオフを何オクターブ上げるか、その減衰時間 |
| `keyTrack` | 0 | 音高に応じてカットオフを動かす割合 |
| `vibratoDepth`, `vibratoRate`, `vibratoDelay` | 0, 5, 0.3 | ビブラート（cent、Hz、開始までの秒） |
| `detune`, `transpose` | 0, 0 | 微調整（cent）、移調（半音） |
| `drive` | 0 | 歪み（0〜1） |
| `gain` | 0.25 | 音色ごとの音量補正 |

### params（ドラム）

| キー | 既定値 | 意味 |
|---|---|---|
| `kit` | `"electro"` | `chip`（ファミコン風）/ `electro` |
| `tune` | 0 | ピッチ（半音） |
| `decay` | 1 | 余韻の長さの倍率 |
| `tone` | 0.5 | 明るさ（0〜1） |
| `gain` | 0.8 | 音量補正 |

## master（全体）

| キー | 説明 |
|---|---|
| `volume` | 全体の音量（0〜1.5）。出力はソフトクリップで ±1 に収まります |
| `reverb.size` / `damp` / `level` | 残響の広さ・高音の吸収・戻りの音量（0〜1） |
| `delay.beats` / `feedback` / `level` | ディレイ間隔（拍。0.75 = 付点8分）・くり返し量・戻りの音量 |

## meta

自由な付加情報です。エディタは AI や設計図から生成した曲の設計図を `meta.plan` に保存します（再生には不要）。

## 互換性

- 読み込み側は `CustomBGM.normalizeScore()` を通すことで、欠けた値・範囲外の値・不正な音符を安全に補正します。
- 未知のキーは無視されます。
