# CustomBGMEditor

ゲーム用 BGM（ループ曲）を打ち込みで作るためのエディタです。
作った楽譜（`.bgm.json`）は、別のセッションの Claude がそのまま読み込んで、ゲームの中でその場で合成して鳴らしたり、WAV に書き出して使ったりできます。

- パートは8つ。各パートは同時に1音まで（ドラム音源のパートだけは同じタイミングに3音まで）
- 電子音寄りの音色 21種（矩形波・三角波・FM・パッド・ベース・チップ/エレクトロのドラムなど）
- イントロ（1回だけ流れる部分）の有無を選べる。ループ部分の長さを常に表示し、3分未満・10分以上で警告
- AI（Claude）に口語で雰囲気を伝えると、テンポ・調・構成・コード進行・伴奏の奏法を決めた「下地」を作る（メロディは作らない）
- WAV 書き出し（試聴用 / ゲーム用1ファイル（ループ位置付き）/ イントロとループの2ファイル）

## 起動方法

インストールは不要です。**`index.html` をブラウザで開くだけ**で動きます（ダブルクリックでOK）。

- 推奨ブラウザ: Google Chrome / Microsoft Edge（最新版）。Firefox / Safari でも動作しますが、保存時に保存先を選ぶダイアログは Chrome / Edge のみです。
- 編集内容はブラウザ内に自動保存されます。大事な曲は「保存」で `.bgm.json` ファイルとして残してください。

## AI で下地を作る

1. 右上の「設定」で Anthropic の APIキーを入力します（キーはこのブラウザ内にだけ保存され、Anthropic の API へ直接送られます）。
2. 「AIで下地を作る」を押し、雰囲気を普段の言葉で書きます。
   例: 「洞窟ダンジョン用。5分くらいのループで、短調、BPMは130前後。チップチューン寄りで、緊張感はあるけど聞き疲れしない感じ。最初に短いイントロを付けて。」
3. AI が「設計図」（セクション構成・コード進行・各パートの役割/音色/奏法）を返します。表の中で自由に直せます。
4. 「この設計図から音符を生成」で、ソフトのルールに従って音符が作られます。メロディ用にパート1・2は空けてあります。

- AI を使わずに「設計図」ボタンからひな形を読み込み、手で設計図を書いて生成することもできます。
- AI の利用には API の従量課金がかかります。既定のモデルは `claude-opus-5-5`、思考の深さは `medium` です（設定で変更可能）。
- 生成は「元に戻す」（Ctrl+Z）で取り消せます。

## 主な操作

| 操作 | 内容 |
|---|---|
| 空き場所をクリック（右へドラッグで長さ） | 音符を置く |
| 音符をドラッグ / 右端をドラッグ | 移動 / 長さ変更 |
| 右クリック（なぞると連続） | 音符を消す |
| Shift＋ドラッグ | 範囲選択 |
| ↑↓（Shiftで1オクターブ）/ ←→ | 選択した音を移動 |
| Ctrl+C / X / V | 音符のコピー・切り取り・貼り付け（カーソル位置へ） |
| ルーラーをクリック / ドラッグ / ダブルクリック | カーソル移動 / 小節範囲の選択 / セクション名の追加 |
| Space / Home | 再生・停止 / 先頭へ |
| 1〜8 | パート切り替え |
| Ctrl+Z / Ctrl+Y / Ctrl+S | 元に戻す / やり直す / 保存 |

範囲を選ぶと、全パートまたは選択パートのコピー・貼り付け・消去・小節の削除・移調ができます。「つなぎ目試聴」でループの終わり→先頭のつながりを確認できます。詳しくは画面右上の「？」を見てください。

## 他のセッションの Claude に渡すとき

楽譜ファイル（`.bgm.json`）と一緒に、このリポジトリの [docs/FOR_CLAUDE.md](docs/FOR_CLAUDE.md) を読むように伝えてください。必要なものはエンジン（`engine/bgm-engine.js`）1ファイルだけです。

- ブラウザゲームなら、その場で合成して再生（`CustomBGM.Player`）
- それ以外のゲームなら、`node tools/render-wav.js 曲.bgm.json --mode split` でイントロとループの WAV を作って使う

楽譜ファイルの仕様は [docs/FORMAT.md](docs/FORMAT.md) にあります。`examples/demo.bgm.json` は設計図のひな形から生成した見本、`examples/player-demo.html` はゲームへの組み込み例です。

## ファイル構成

```
index.html            エディタ本体（これを開く）
css/style.css
js/app.js             編集状態・履歴・制約・再生の管理
js/pianoroll.js       ピアノロール
js/panels.js          パート一覧・音色/曲/セクションのパネル
js/main.js            上部の操作・ダイアログ・ショートカット
js/arranger.js        設計図 → 音符のルール生成器
js/ai.js              Claude API との通信
engine/bgm-engine.js  音源エンジン（再生・WAV書き出し。単体で配布可能）
tools/                Node.js 用コマンド（WAV書き出し・楽譜の確認）
tests/run-tests.js    テスト（node tests/run-tests.js）
docs/                 仕様書と Claude 向けガイド
examples/             見本の楽譜と再生デモ
```
